# Where PDP-11 diagnostics can be found, for File > Collect diagnostics.
#
# Each block is one web directory. Its index page is read, the links that stay inside it are
# followed (into subdirectories only with recurse = yes), and every file whose name matches an
# include pattern is offered. "mirror" lines are tried, in order, when "url" does not answer.
# See DiagnosticSource for the format; a test reads this file and fails on a mistake in it.
#
# Nothing here is shipped with the application. These are other people's archives, and the
# application only fetches from them when the person running it asks it to.
