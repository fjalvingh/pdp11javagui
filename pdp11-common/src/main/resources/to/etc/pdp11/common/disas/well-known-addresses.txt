# Well-known PDP-11 addresses, for the comments the disassembler puts after an instruction that
# names one.
#
# One line each:   address[-last]  NAME  description
#
# Addresses are octal and 16-bit, which is what a disassembly is in: the I/O page is 160000-177777
# whatever the width of the machine. A range names a block (a ROM) rather than a register, and a
# name of "-" means the description says it all. Where two devices share an address - TM11 and
# TS11 do - give the address twice and both are shown. Only fixed, factory-default addresses
# belong here: a floating-address device (DZ11, DH11, ...) is wherever its owner put it, and a
# comment naming it would be a guess. WellKnownAddressesTest reads this file and fails on a
# mistake in it.
